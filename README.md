# NEXUS VITALIS

**Human-Aware Adaptive Intelligence Platform**

NEXUS VITALIS is an independent Android-native project exploring
privacy-first adaptive experiences using real-world signal quality
and user-controlled interaction.

## Current milestone

Foundation build 0.1.0:

- Native Android application using Kotlin.
- Android SDK 36.1.
- JDK 17, Gradle 8.13, AGP 8.13.2.
- GitHub Actions Android build pipeline.
- Minimum Android SDK: 28.

## Product direction

The initial product is an Adaptive Focus Companion.

Future milestones may integrate:

- Presage SmartSpectra Android SDK.
- Local signal-quality processing.
- A user-controlled adaptive policy engine.
- Optional AI-assisted recommendations.

## Privacy and safety

- No medical diagnosis or treatment claims.
- No camera acquisition in this foundation build.
- No biometric data collection in this foundation build.
- No raw video storage.
- No API keys or credentials committed to source control.
- User consent and local policy enforcement are required
  before introducing sensor-based functionality.

## Current limitations

This foundation build does not yet integrate SmartSpectra,
measure vital signals, or implement adaptive focus decisions.

A successful CI build is not proof of sensor integration.
